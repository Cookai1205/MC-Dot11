# Dot11／11點
Adds **Cubic 11** and supplementary characters to the game. Supports all Chinese<sup>1</sup> in-game texts (as of 26.3).  
加入**俐方體11號**及自製補字，支援所有中文<sup>1</sup>遊戲文本（截至 26.3）。

This pack also modifies the basic Latin letters and symbols of Mojangles, shortening the height to 6px, making the mixed Chinese and English text more balanced. Turn OFF "Force Unicode Font" to use the modified Mojangles.  
本包還修改了 Mojangles 的基本拉丁字母及符號，將高度縮短為 6px，使中英混排更美觀。關閉「強制使用 Unicode 字型」以使用修改版 Mojangles。

<sup>1</sup> including `zh-tw`, `zh-hk`, `zh-cn`, not `lzh`.

## Feature／功能
* `ttf` + `bitmap` font.  
  `ttf` + `bitmap` 字型。
* Supports all in-game texts for `zh-tw`, `zh-hk`, `zh-cn` (as of 26.3).  
  支援 `zh-tw`、`zh-hk`、`zh-cn` 的所有遊戲文本（截至 26.3）。

## Reminder／使用注意
* Cubic 11 is a `ttf` font with thinner strokes than Mojangles; therefore, there will be rendering issues for bold text and glowing text.  
  本包中的俐方體11號是 `ttf` 字型，並且筆畫較 Mojangles 細，因此粗體效果和發光效果會有顯示問題。
* GUI scale `3` and `6` can ensure no distortion for Cubic 11.  
  俐方體11號的字身框為 12×12，因此在介面大小 `3` 和 `6` 能確保不失真。
